# 🔐 Cybersecurity Chatbot (WPF Application)


---

## 🖥️ Overview
This project is a **WPF (Windows Presentation Foundation) application** designed as an interactive **cybersecurity chatbot**.  
It combines a modern graphical interface with educational chatbot features to help users understand key cybersecurity concepts.

---

## ✨ Features
- **WPF User Interface**  
  - Clean, responsive design with buttons, textboxes, and dialog windows.  
  - Intuitive layout for entering queries and viewing chatbot responses.

- **Cybersecurity Chatbot Engine**  
  - Recognizes keywords such as *phishing*, *malware*, *firewall*, *password security*.  
  - Provides clear, concise explanations of cybersecurity topics.  
  - Supports expandable keyword-response pairs via external JSON file.

- **Interactive Enhancements**  
  - Image banner displayed at startup.  
  - Optional voice greeting using `System.Speech.Synthesis`.  
  - Error handling for invalid or unknown inputs.

---

## 📂 Project Structure
- Start with a homepage where it introduces you to the chatbot with a voice greeting
- Once proceed, enter your name and click proceed
- The console will either welcome you back or it will welcome you as a new user
- Enter your question where it will answer you with cybersecurity related topics
- The app also recognises your favorite topic and saves it to a text file
